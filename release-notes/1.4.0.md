# OnlyEQ 1.4.0

A design release. Nothing about the sound changed.

- The popover is now one instrument instead of a stack of cards: the live curve fills the left half at full height, and the controls stand in one column on the right in signal order: output device and volume, preset with the device it is bound to, Bypass and Crossfeed, then Import…, Equalizer, and the gear. The status pill sits in the corner of the plot. Escape closes the popover.
- The panel uses the system's own menu-bar material: Liquid Glass on macOS 26, the popover vibrancy before it.
- The menu-bar icon fills while the EQ shapes sound and outlines while it is off or bypassed, so the state reads without opening anything.
- The equalizer window draws its toolbar in the title bar, as document windows do, and Settings opens in its own window (⌘,) instead of replacing the equalizer.
- Onboarding follows the macOS setup-assistant pattern: one panel, Back and Continue. The welcome panel shows a real headphone correction curve rather than an icon.
- The import sheet's drop zone names its state: "Drop a preset file here", "Release to import".
- `--screenshots` renders the light appearance too with `--light`.
