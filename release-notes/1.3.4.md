# OnlyEQ 1.3.4

- Loudness-matched bypass. Bypass now measures how much loudness the bands add on what is playing (K-weighted, three-second average) and applies that gain to the bypassed signal, so A/B comparisons are about tone, not level. Turning the EQ off entirely still passes audio at unity.
- True-peak limiter. The limiter reacts to the reconstructed waveform between samples, so the ceiling holds on a DAC instead of being missed by up to 3 dB on inter-sample peaks. The editor's peak meter reads true peak too.
