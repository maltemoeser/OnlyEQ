# OnlyEQ 1.3.2

- The spectrum is tilted 2 dB per octave so typical music reads flat; before, every recording looked bass-heavy and the treble bars barely moved.
- Bars now show band power with a calibrated scale, so a full-scale sine reads 0 dBFS and wide and narrow bands are comparable.
- Meter-style ballistics: 10 ms attack, 400 ms release. Transients still register, but the display no longer flickers.
