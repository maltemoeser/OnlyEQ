# OnlyEQ 1.4.1

The 1.4.0 release never published: the build runner's SDK predates the macOS 26 glass view. This release carries everything 1.4.0 described.

- The glass panel is compiled only with the macOS 26 SDK; older toolchains build the popover vibrancy fallback everywhere.
- Releases now build on the macOS 26 runner, so installed copies on macOS 26 get the glass panel.
