# OnlyEQ 1.3.7

- Undo in the editor. Every preset edit (moving or adding a band, changing a value, deleting a band, changing the preamp, switching or reverting a preset) is one Command-Z step; Command-Shift-Z redoes. A drag undoes as a single step.
- The Delete key removes the selected band. The band card's delete button has a larger target and a VoiceOver name.
- Deleting a stored preset asks first, from both the popover and the editor.
- The Save sheet says when the typed name replaces another stored preset, and its button reads Replace.
