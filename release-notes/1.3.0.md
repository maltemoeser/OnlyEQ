# OnlyEQ 1.3.0

First release of the maltemoeser fork. Compared to upstream 1.2.7:

- Bypass replaces the Flat button and hotkey, and keeps the preamp for a level-matched A/B.
- Headphone crossfeed and loudness compensation.
- Matched (decramped) biquad design for all filter types.
- Applied imports are saved and stay in the preset picker.
- Simpler popover and editor, with settings inside the editor window.
- Updates come from this fork's GitHub Releases.
- Fixes from a whole-codebase review: no allocation on the audio thread, excluded apps honoured when launched later, corrupt preset files preserved, gain-less filter lines imported.
