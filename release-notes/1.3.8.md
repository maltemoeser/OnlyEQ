# OnlyEQ 1.3.8

- Text follows the system text size. Every label in the popover, editor, settings, import sheet, and onboarding uses a macOS text style instead of a fixed point size, so Accessibility › Display › Text Size applies. The popover grows in height to fit.
- VoiceOver and keyboard. The master switch is focusable, toggles with Space, and reads as a switch named "Enable EQ". The band value fields are buttons that open for editing, with the field name and value spoken. The gear menus, add and remove app buttons, and add and delete band buttons have names.
